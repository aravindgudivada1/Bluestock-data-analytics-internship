4. LIVE API VALIDATION

The AMFI scheme codes specified in the Day 1 assignment were tested
against the live mfapi.in API.

A discrepancy was identified between several scheme-code mappings in
the provided Bluestock Fund Master / assignment and the metadata
currently returned by the live API.

Example:
Bluestock Fund Master:
125497 -> HDFC Top 100 Fund - Direct Plan - Growth

Live API response:
125497 -> SBI Small Cap Fund - Direct Plan - Growth

Similar mapping discrepancies were observed for several other
assignment-provided scheme codes.

The raw API responses were preserved using the metadata actually
returned by the API. No API response was manually relabelled to force
a match with the provided Fund Master.
